# 小安式 組織改革OS — ビジョン

## これは何か

組織改革コンサルにおいて、一社ごとの問題を**課題一覧で終わらせない**ためのパーソナルワークスペース。

現象の把握から、本質構造の理解、レバレッジポイントの特定、打ち手の検討、学びのSKILL化までを一気通貫でつなぐ **「思考OS」** を目指す。

## 解決したいこと

- 現場の現象・違和感が、スプレッドシートや会議メモに散らばる
- 構造分析と打ち手検討が別資料になり、「今どこを見るべきか」が失われる
- コンサルタント個人の判断基準・SKILLが属人化する

## 4ペインの役割

| ペイン | 名称 | 役割 |
|--------|------|------|
| Pane1 | 現象とA00 | 現場の現象・違和感・兆候、案件A00（北極星）、現象ごとの目指す姿 |
| Pane2 | 構造分析 | 人・関係性・制度・会議・評価・心理安全性などの構造 |
| Pane3 | レバレッジと打ち手 | どこを押せば構造が動くか、具体の打ち手候補 |
| Pane4 | 学びと成果 | 実行結果・気づき・成長・次のSKILL化 |

## 設計原則

1. **案件データとコンサル思想を分離する**（詳細は [data-boundary.md](./data-boundary.md)）
2. **まず見える化、次に記憶、最後に分岐**（if-then 介入シナリオは将来フェーズ）
3. **Pane2・Pane3 は将来の詳細画面に拡張できる**（MVP は静的＋最小操作）
