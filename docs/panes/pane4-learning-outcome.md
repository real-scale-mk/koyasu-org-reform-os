# Pane4 — 学びと成果

> **ステータス:** grill-me 確定（2026-06）

## 役割

小安式 OS の**中核** — 介入の結果から **学び・気づき・SKILL 化** を蓄積するペイン。

単なる成果管理ではない。

```
結果 → 気づき → 再利用可能な SKILL
```

小安式 5 段フローの末端：

```
Pane1  現象
Pane2  構造分析
Pane3  レバレッジ → 打ち手
Pane4  学び・成果  ← ここ
```

採用ひな形の「選考進捗」に相当する。Pane1 選択現象に連動する。

---

## 情報構成（確定）

4 セクション、**上から下**が小安式の流れ：

| # | セクション | 意味 |
|---|-----------|------|
| 1 | **実行結果** | 打ち手を試した結果 |
| 2 | **成果** | 定性的・定量的な変化 |
| 3 | **気づき** | 現場・クライアントとの対話から得た洞察 |
| 4 | **SKILL化候補** | 次の案件に持ち越す判断基準・手順 |

## デモ seed：若手離職（初期選択）

**1. 実行結果（静的）**

- 改革チーム立上げ：第1回キックオフ実施。決裁ルール案を起草。
- 1on1 対話設計：2名の課長で試行開始。

**2. 成果（静的）**

- 会議で「誰が決めるか」を明示した場面が月3回→8回に増加（自己申告）

**3. 気づき（編集可・初期 seed）**

- 責任曖昧が「会議の持ち帰り」として現れることが、若手離職の直接トリガーになっている可能性

**4. SKILL化候補（編集可・初期 seed）**

- 会議観察チェックリスト：決裁者明示 / 持ち帰り回数 / 越境問題の止め方
