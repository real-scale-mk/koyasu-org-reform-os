# Pane3 — レバレッジと打ち手

> **ステータス:** grill-me 確定（2026-06）

## 役割

**どこを押せば構造が動くか**（レバレッジ）と、**実際に行う施策**（打ち手）を扱うペイン。

小安式 5 段フロー：

```
Pane1  現象        → 何が起きているか
Pane2  構造分析    → なぜ続くか
Pane3  レバレッジ  → 構造を変えるポイント ★
       打ち手      → 実際に何をするか
Pane4  学び        → 実行して何が得られたか
```

採用ひな形の「面接評価」に相当する。Pane1 選択現象に連動する。

**重要:** レバレッジと打ち手は**混ぜない**。打ち手の一覧ではなく、**なぜその打ち手なのか**が分かる構造を重視する。

### デモ seed：若手離職（初期選択）

**★ レバレッジ:** 会議での決裁・役割の明示  
**接続:** 責任曖昧 → 会議での責任押付けの悪循環を止める

| 打ち手 | なぜ（要約） | 概要（要約） |
|--------|-------------|-------------|
| 改革チーム立上げ | 決裁ルールを全社で統一するため | 部門横断の改革チーム |
| 1on1 対話設計 | 課長が「誰が決めるか」を明示するため | 月1回1on1で決裁確認 |
| 小さな成功実験 | 1会議から決裁ルールを試すため | 次回会議で決裁者を明示 |

他現象の seed は **最小プレースホルダ**（[data-boundary.md](../data-boundary.md) §4現象 seed 方針）。若手離職のみフル seed。
